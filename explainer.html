Where it goes

What this makes possible

National visibility, live

Government can watch group formation and loan health across every region in real time, instead of waiting for quarterly returns.

Faster, safer lending

Banks act on a verified group profile and a clean application trail — approval to disbursal in one auditable flow.

Every decision accountable

Nothing is deleted, quorate meetings gate the big choices, and every step names who did it and when.

Built to grow

The design is scalable — subject to some hardware upgrades for security, from four demo groups to hundreds of real ones with the same rules, the same structure. No software redesign or upgrades are needed.

Under the hood

How it's built

A deliberately small, modern stack — managed services do the heavy lifting, with almost nothing to run ourselves.

Software

A browser app, no server to run

The interface is a single self-contained web page (HTML & JavaScript). There's no custom application server to build or maintain — it talks straight to the managed backend.

Database

PostgreSQL, managed by Supabase

Every record — groups, meetings, loans — lives in one PostgreSQL database. The rules for who can see and change what are enforced inside the database itself (Row-Level Security).

Cloud

Hosted on Supabase's cloud

Supabase provides the database, a secure auto-generated API, and login as managed cloud services. The web page can be served from any static host or CDN — nothing runs on our own hardware.

Capacity. A single managed instance comfortably covers the pilot — dozens of concurrent users and thousands of groups, with headroom to spare. Growing to national volumes (hundreds of thousands of records and hundreds of simultaneous users) is a matter of moving to a larger instance tier and adding read replicas — not a redesign.
Cost

Little to no running cost

A pilot or demo of this size runs on free tiers at effectively zero cost. Production scale needs only a modest managed plan (on the order of tens of dollars a month) for backups and support — no servers, licences or infrastructure to buy.

Portability

Can move on-premise

It's standard PostgreSQL plus a static web page, and Supabase is open-source — so it can be rehosted on a government server or private cloud. That's mainly setup and IT effort, not a rewrite; the app and data carry across unchanged.

Security

Room for stronger safeguards

Data is already encrypted in transit and at rest. For sensitive records, extra layers slot on top: real passwords with two-factor or single sign-on, encryption of personal fields, full audit logging, network restrictions, and periodic security testing.
